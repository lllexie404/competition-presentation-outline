# 竞赛汇报大纲生成器 Competition Presentation Outline

将「从产品/系统方案文档 → 生成面向竞赛评审的汇报大纲」这一高复用流程封装为可复用 Skill。核心目标：让产出的大纲**对齐评审维度、节奏可控、话术分众、追问有备**。

## 这是什么

本 Skill 接收一份产品/系统方案文档，自动生成面向企业技能竞赛、产品评审、方案路演等场景的结构化汇报大纲，包含评审维度映射、时间分配、每页讲解稿、追问支撑与多格式产出。

> 入口文件：`SKILL.md`

## 适用场景

- 用户有一份产品/系统方案文档，需要面向竞赛评审产出结构化汇报大纲。
- 用户要求生成企业技能竞赛、产品评审、方案路演的汇报大纲。
- 用户提到「12 分钟汇报」「PPT + 系统 DEMO」「评审维度汇报」等场景。

## 产出内容

- 结构化汇报大纲（HTML / MD / PPTX 三格式）
- 评审维度 × 章节 × 落点映射表
- 时间分配图 + 六维度覆盖雷达图
- 每页「论点 + 支撑点 + 讲解稿」三件套（含业务化「一句话纲领」）
- 评审追问支撑附录（Q-x，含业务/技术双话术）
- 超时降级预案（必演 / 可压缩 / 可跳三级分级）
- 证据强度标注（supported / stated-only / inferred）
- DEMO 衔接脚本与桥接话术

## 输入 Schema

| 字段 | 类型 | 必填 | 说明 |
| --- | :-: | :-: | --- |
| `document` | file | 是 | 原始产品/方案文档（MD/Word/PDF） |
| `duration_minutes` | number | 是 | 汇报总时长（分钟） |
| `presentation_format` | enum | 是 | `ppt` / `ppt_demo` / `speech` |
| `audience` | enum | 是 | `business` / `technical` / `mixed` |
| `positioning` | enum | 否 | `client_internal` / `vendor_delivery` / `default` |
| `evaluation_dimensions` | array | 是 | 评审维度列表（名称+权重可选） |
| `industry` | enum | 否 | 金融/能源/制造/互联网等 |
| `output_formats` | array | 否 | `html` / `md` / `pptx` / `all` |

## 六步主流程

1. **需求澄清与骨架选型**：收集竞赛类型、时长、形式、受众、评审维度、行业赛道，选定并融合叙事骨架。
2. **内容映射与时间分配**：抽取文档核心信息，建立维度×章节×落点映射，做时间分配与优先级分级。
3. **细节填充与话术打磨**：每页「论点+支撑+讲解稿」、一句话纲领、三层冗余控制、业务化翻译。
4. **交叉复核**：六层逻辑模型（结构/内容/一致性/时间/证据/受众）逐层核验。
5. **评审追问预判**：识别高概率追问点，生成 Q-x 备查答案（业务+技术双话术）。
6. **多格式产出**：同一结构化数据渲染为 HTML / MD / PPTX / DEMO 脚本。

## 边界声明

- 本 Skill 解决「从文档到大纲的结构化编排与话术化包装」。
- **不替代**对方案本身深度的判断、创新点的战略拔高。
- 生成后需人工复核内容准确性。
